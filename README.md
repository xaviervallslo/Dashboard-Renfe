## 📊 RENFE Precios y Viajes – Dashboard Interactivo

Este dashboard ha sido diseñado para visualizar y analizar datos relacionados con los precios y viajes de RENFE, la principal operadora ferroviaria de España. Utiliza una interfaz intuitiva y segmentada que permite explorar la información de forma clara y eficiente.

### 🧭 Navegación

El panel está estructurado en cinco secciones principales, accesibles tanto desde botones destacados como desde una barra de pestañas inferior:

- **Portada**: Página de bienvenida o introducción al informe.
- **Resumen**: Vista general con métricas clave y visualizaciones agregadas.
- **Viajes**: Detalles sobre trayectos, frecuencias, destinos y patrones de movilidad.
- **Precios**: Análisis de tarifas, variaciones por ruta, clase y temporalidad.
- **DataSet**: Acceso directo al conjunto de datos utilizado para alimentar el dashboard.

### 🎨 Diseño

- Estética limpia y profesional con una paleta de colores centrada en tonos púrpura.
- Botones grandes y redondeados para facilitar la navegación.
- Tipografía clara y jerarquizada para destacar títulos y secciones.

### 🛠️ Tecnologías utilizadas

- Power BI para la creación del dashboard.
- Fuentes de datos estructuradas (CSV, Excel o bases de datos relacionales).
- Posible integración con servicios de RENFE para actualización dinámica.
